NGC.csv and addendum.csv are redistributed unchanged. The app derives names,
ICRS coordinates and target recommendations from these files. Common names,
where present, are from the catalogue, not generated. Missing common names use
Messier or NGC/IC identifiers. See the upstream README for constituent data
sources and acknowledgements. Derived catalogue data retains CC BY-SA 4.0.
